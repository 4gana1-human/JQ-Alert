# JQ Alert

[![Chrome Web Store](https://img.shields.io/chrome-web-store/v/eicpbodfpiaimdkjbmbiomgefjflgibj?label=Chrome%20Web%20Store)](https://chromewebstore.google.com/detail/eicpbodfpiaimdkjbmbiomgefjflgibj?utm_source=item-share-cb)
[![Chrome Web Store Users](https://img.shields.io/chrome-web-store/users/eicpbodfpiaimdkjbmbiomgefjflgibj)](https://chromewebstore.google.com/detail/eicpbodfpiaimdkjbmbiomgefjflgibj?utm_source=item-share-cb)

JQ Alert は、緊急地震速報（予報・警報）、地震情報、津波情報を確認・通知する Manifest V3 対応の Chrome 拡張機能です。

速報はあくまで避難行動や情報収集を補助するためのものです。緊急時は、テレビ・ラジオ・気象庁・自治体などの信頼できる情報源も必ず確認してください。

## インストール

[Chrome ウェブストアから JQ Alert を追加する](https://chromewebstore.google.com/detail/eicpbodfpiaimdkjbmbiomgefjflgibj?utm_source=item-share-cb)

対応環境は Google Chrome 116 以降、および Chrome 拡張機能に対応した Chromium ベースのブラウザです。

導入方法と基本的な使い方は、[こちらの解説](https://note.com/4gana1_human/n/nda506f9bfcc6?sub_rt=share_pw)もご覧ください。

## 主な機能

### 緊急地震速報（EEW）

- 緊急地震速報の予報・警報を受信し、デスクトップ通知でお知らせ
- 通知する震度、対象都道府県、予報／警報、通知する報（すべて・第一報・第一報と最終報・最終報のみ）を設定可能
- 通知レベルのプリセット（少なめ・標準・すべて）を用意
- 最大震度が変化した続報の通知、および通知しない時間帯を設定可能
- 同じ地震に対する続報・最終報・取消報を区別して処理

### JQA 防災情報モニター

EEW受信画面では、次の情報をタブで切り替えて確認できます。

- **EEW**: 震源、マグニチュード、予想最大震度、震度4以上が予想される地域、P波・S波の予報円
- **強震モニタ**: リアルタイムの震度表示と最大加速度表示
- **震度マップ**: 地震ごとの観測震度を地図と地点アイコンで表示。震源アイコンと地点アイコンが重なる場合は、震源アイコンを半透明にして数値を見やすく表示
- **津波**: 津波情報、対象地域、観測情報を地図で確認

受信画面は自動表示・前面表示・ウィンドウサイズ・最終報後の表示時間を設定できます。地震情報または津波タブを表示中にEEWを受信した際、EEWタブへ自動で切り替えるかも選択できます。

### 地震情報・津波情報の通知

- 地震情報と津波情報の更新を、それぞれ個別に通知可能
- 受信画面の震度マップ・津波タブで、保存された最新情報と履歴を確認
- 地震・津波情報の通知にも「通知しない時間帯」の設定を適用

### 音声・読み上げ

- 予報・警報ごとに通知音の有効化、音量、任意の音声ファイルを設定
- 緊急地震速報の内容を音声で読み上げ
- 読み上げ文はテンプレートでカスタマイズ可能。震源地、マグニチュード、最大震度、津波情報などの変数に対応
- 警報の続報を読み上げ直す条件を選択可能

通知音と音声読み上げは、EEWを受信した時点で受信画面が開いている場合に動作します。音声読み上げの設定・実行は日本語表示時のみ対応しています。

### 現在地の地震波到達状況

- 保存した現在地について、受信画面に「未到達・P波到達・S波到達」を表示
- ブラウザの位置情報取得、または緯度・経度の手動入力に対応
- 保存前に地図上のピン位置を確認可能

到達予想時刻・残り秒数・予測震度を示す機能ではありません。

### そのほか

- EEW受信時に指定したURLを新しいタブまたはウィンドウで自動的に開く「オートリンク」
- ポップアップからの最新地震情報の確認と、受信画面の手動表示
- 通知・通知音・読み上げの動作を確認するテスト通知と診断情報のコピー
- 日本語、英語、韓国語、簡体字中国語、繁体字中国語の表示に対応
- 拡張機能内のお問い合わせフォーム、返信履歴、未読返信の表示

## 初期設定のおすすめ

1. 拡張機能のアイコンをクリックし、設定画面を開きます。
2. **EEW通知条件**で「緊急地震速報を通知する」を有効にします。
3. 通知レベルを選ぶか、対象都道府県・予想震度・予報／警報・通知する報を詳細設定します。
4. 必要に応じて、受信画面の自動表示、通知音、読み上げ、地震・津波情報通知を設定します。
5. 現在地の到達状況を利用する場合は、位置を確認してから保存します。

ChromeやOS側で通知が許可されていない場合、拡張機能側の設定が有効でもデスクトップ通知は表示されません。設定後は「通知テスト・動作診断」で確認してください。テスト通知では、オートリンクや受信画面は開きません。

## 利用上の注意

- [気象庁「緊急地震速報について」](https://www.data.jma.go.jp/svd/eew/data/nc/)を確認し、緊急地震速報の性質と限界を理解したうえで利用してください。
- 配信元やネットワーク、ブラウザ、端末の状態により、情報の遅延・欠落・表示不能が発生する可能性があります。JQ Alertは情報の正確性、即時性、継続的な提供を保証するものではありません。
- 本拡張機能は補助的な情報提供手段です。避難や安全確保が必要な場合は、公的機関・放送・自治体からの情報を優先してください。
- 本拡張機能で取得した情報の二次配信・再配信は行わないでください。
- 自動化や短時間での繰り返し操作など、過度な情報取得は行わないでください。配信元の応答遅延や、[P2P地震情報 JSON API v2](https://www.p2pquake.net/develop/json_api_v2/)からのアクセス制限（HTTP 429）につながる場合があります。

## 情報の取得元

JQ Alertは、以下の情報を利用しています。各情報提供元の障害・仕様変更などにより、機能の一部が利用できなくなる場合があります。

| 用途 | 情報提供元 |
| --- | --- |
| 緊急地震速報 | [Wolfx Project](https://wolfx.jp/)、[Project BS Telegram-CF](https://telegram-cf.projectbs.cn/ja-JP) |
| 地震情報・津波情報 | [P2P地震情報](https://www.p2pquake.net/) |
| 津波情報の補完 | [気象庁 防災情報XML](https://www.data.jma.go.jp/developer/xml/feed/eqvol.xml) |
| 強震モニタ表示 | 防災科学技術研究所・LY Corporation の配信データ |

## プライバシーと保存データ

- 通知条件、画面設定、音声設定などは Chrome の拡張機能ストレージに保存されます。
- 現在地の到達状況で保存した座標は、拡張機能内でのみ使用します。位置確認の地図を表示している間は、その確認地図の提供元へ座標が送信されます。
- お問い合わせフォームから送信した内容は、問い合わせ対応のためサポート用データベースに送信されます。返信用メールアドレスは任意です。

## 開発環境で読み込む

このリポジトリはビルド手順を必要としません。

1. リポジトリを取得します。
2. Chromeで `chrome://extensions/` を開き、右上の「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を選び、このリポジトリのルートフォルダーを指定します。
4. ファイルを変更した後は、拡張機能カードの再読み込みを実行します。

Manifest V3 のService Workerを使用しています。WebSocketの接続・再接続、通知条件、EEWの重複排除・続報処理を変更する場合は、通常報・最終報・取消報・順序逆転・複数配信元からの重複受信を確認してください。
